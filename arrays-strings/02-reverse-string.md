## Problem: Reverse a String (Easy)
**Link:** https://leetcode.com/problems/reverse-string/

### Approach
I used a two-pointer approach, setting one pointer at the beginning and one at the end of the string, swapping the characters, and moving inward until they met in the middle.

### Complexity
- Time: $O(n)$
- Space: $O(1)$

### Notes
This modifies the string in-place, which is highly efficient for memory.
